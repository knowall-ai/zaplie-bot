= Glossary of Terms
:toc:

Acronyms, terms, and definitions used in this project.

== Acronyms

[cols="1,3"]
|===
| Acronym | Definition

| AAD
| Azure Active Directory (now Microsoft Entra ID) — Microsoft's cloud identity provider

| API
| Application Programming Interface

| CI/CD
| Continuous Integration / Continuous Deployment

| CRA
| Create React App — the toolchain used by the `tabs/` web application

| LNURL
| Lightning Network URL — a protocol family for Lightning payment interactions (e.g. LNURL-pay)

| MSAL
| Microsoft Authentication Library — used by the web tabs for Entra ID sign-in

| SPA
| Single-Page Application

| SSO
| Single Sign-On

| UI/UX
| User Interface / User Experience

|===

== Domain Terms

[cols="1,3"]
|===
| Term | Definition

| Bitcoin Lightning Network
| A second-layer payment network on top of Bitcoin enabling instant, low-fee micro-transactions

| LNbits
| An open-source Lightning wallet and account system. Zaplie uses an LNbits instance to hold and move Sats between user wallets

| Sat (Satoshi)
| The smallest unit of Bitcoin (1 BTC = 100,000,000 Sats). The unit of recognition in Zaplie; administrators can rename it

| Zap
| Sending Sats to a colleague as recognition or reward — the core action in Zaplie

| Wallet
| An LNbits sub-wallet belonging to a user. Each Teams user is provisioned wallets automatically

| Allowance
| The initial balance of Sats granted to a user's wallet, controlled by `LNBITS_INITIAL_ALLOWANCE`

| Adaptive Card
| A Microsoft card format used by the bot to render interactive UI (e.g. the Send Zap form) inside Teams

|===

== Platform Terms

[cols="1,3"]
|===
| Term | Definition

| Teams Bot
| The conversational bot component (root of this repository) built on the Microsoft Bot Framework

| Tabs
| The React web application (`tabs/` directory) surfaced as tabs inside the Teams app

| Azure Functions
| Serverless HTTP endpoints (`functions/` directory) for user and Zap operations

| Teams Toolkit / TeamsFx
| Microsoft tooling (`teamsapp` CLI) used to provision, deploy, and preview the Teams app

| Bot Framework
| Microsoft's SDK (`botbuilder`) for building conversational bots

|===
